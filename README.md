# ParaBank QA Project

This project documents a manual QA testing portfolio for the ParaBank Demo Banking Application.

## Project Scope

The current phase focuses on manual functional testing through the web user interface.

## Documentation

- `docs/TEST_PLAN.md` — Defines the testing scope, objectives, risks, environment, and deliverables.
- `docs/TEST_STRATEGY.md` — Explains the testing approach, prioritization, evidence strategy, and regression strategy.
- `docs/test-cases/PARABANK_15_TEST_CASES_EN.md` — Contains 15 functional manual test cases.
- `docs/BUG_REPORTS.md` — Contains the bug reporting structure, severity/priority definitions, and defect documentation template.
